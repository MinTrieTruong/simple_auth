# Simple Auth - Lab 6

Ứng dụng minh họa cách thực hiện xác thực người dùng bằng **Basic Auth** và **Cookie/Session** trong Node.js.
Đã thêm MSSV và Họ tên hiển thị lên tất cả các trang.

---

## Cài đặt & Chạy

```bash
npm install
node basic_auth.js    # kiểm tra Basic Auth
node cookie_auth.js   # kiểm tra Cookie + Session
Kết quả
Đây là các màn hình của ứng dụng:

1. Register
2. Login
3. Profile
4. Logout
